# 卡槽背景 PSD 模板

作者原文件位于外层 `STS1_素材/模板真.psd` 和 `STS1_素材/模板·改.psd`，保持原文件不变，制作时另存副本。

两份画布均为 **301×461**，RGBA，圆角外透明；与当前 `FrierenMod/images/slot_backs/*.png` 尺寸一致。

- **模板真**：一层“矩形 1”，保留矢量形状与描边信息，是基础圆角轮廓。
- **模板·改**：同样的“矩形 1”，另有“图层 3”装饰，合成预览能看到上下金色花纹框。
- 这两份文件没有预置的智能对象换图层；不能把它们当成“双击智能对象、替换图片”的模板。

使用时放入新主体图，保持比例移动、缩放到画布内，使用矢量轮廓或对应蒙版裁切。带框版本保留装饰图层，使主体不遮住金色框。白色区域是待放图区域，不应作为最终白色背景盖住主体。

按 **301×461 画布**导出透明 PNG。装饰图层存在画布外内容（横向范围约为 -113 到 441），不要按“所有图层边界”扩画布或整体缩放，否则卡背比例和边框会变。圆角外不能填成白色或黑色。

一代104张卡槽背景保持原样；二代新增23张，使用独立8001～8023号段，清单见 `inventory/sts2_slot_backs.json`。0.12.13按作者填写表接入22组条件及全部成就名称、说明；8019等待作者新增“圣雪结晶”事件后接入，保持锁定。新增背景不进入原有通关随机奖励池。可从原生档案确认的胜场、卡牌取得／发现及敌人击败记录补发；累计委托存入卡背收藏档案，以原生跑局开始时间和委托ID去重，当前旧档仍存在的已完成委托可以补计。过去跑局未曾保存的委托完成次数无法追溯。

## 制作截图预览

`tools/create-slot-back-previews.mjs` 直接读取两份原始 PSD 的圆角透明轮廓、描边及“图层 3”装饰，将截图等比例裁切后合成，不重画原图。装饰先裁到原画布，避免图层越界导致比例变化。每张截图输出“金色花纹”“基础圆角”两个301×461透明PNG，另有总览和能展开原图对照的本地HTML。

运行需要 Node.js 和 sharp；sharp不在正常模块路径时用环境变量 `SHARP_MODULE` 指向其安装目录。

```powershell
node tools/create-slot-back-previews.mjs inputs.json outputs/slot-back-preview
```

`inputs.json` 示例（路径指向各自机器的原文件）：

```json
{
  "basicTemplate": "D:/素材/模板真.psd",
  "decoratedTemplate": "D:/素材/模板·改.psd",
  "images": [
    { "name": "芙莉莲·微笑", "source": "D:/素材/截图.png", "focus": [0.5, 0.5] }
  ]
}
```

`focus` 是期望保留的中心，两个值分别为横向和纵向0～1。每张图可选填 `sourceRect`（`left`、`top`、`width`、`height`，原图像素坐标），此时 `focus` 相对此区域；`fit` 默认为等比铺满的 `cover`，双人等构图可用 `contain` 保留整个区域；`background` 可指定透明原图的底色，例如 `#ffffff`。顶层 `columns` 可指定总览列数（1～8）。成品附带实际原图裁切坐标及模板图层，便于调整。工具只支持这两份模板使用的8位RGB、RAW/RLE和普通混合图层，遇到其他混合方式会停止。

## 补充旧成品的材质

原PSD没有保存旧成品的倒角、内缘折线和主体浮雕效果。`tools/materialize-slot-backs.mjs` 将内置imagegen生成的中性透明倒角素材合成到原PSD套图，再对原画的已有轮廓作亮度方向差处理。主体构图不变，不使用生成式重画人物。

```powershell
node tools/materialize-slot-backs.mjs outputs/slot-back-preview-20261029 outputs/slot-backs-final-20261029 --candidates
node tools/materialize-slot-backs.mjs outputs/slot-back-preview-20261029 outputs/slot-backs-final-20261029
```

输出目录须先具备 `制作素材/倒角材质-生成原稿.png`。`--candidates` 比较原套图及轻、中、重三种强度；实际成品取适中档，约8px倒角、7.5px内折线及受限的浅浮雕。金色装饰单独降低饱和度并提高轮廓明暗，避免平面贴花感。

最终38张PNG位于 `outputs/slot-backs-final-20261029/`，全部保持301×461，透明轮廓与套图逐像素一致；附前后对照、旧图参考对照、总览和HTML。风格以旧图中的彩色浅浮雕款为目标，具体原作者滤镜参数未能从PNG还原。尚未替换游戏资源。
