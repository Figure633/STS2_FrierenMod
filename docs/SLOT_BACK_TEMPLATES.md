# 卡槽背景 PSD 模板

作者原文件位于外层 `STS1_素材/模板真.psd` 和 `STS1_素材/模板·改.psd`，保持原文件不变，制作时另存副本。

两份画布均为 **301×461**，RGBA，圆角外透明；与当前 `FrierenMod/images/slot_backs/*.png` 尺寸一致。

- **模板真**：一层“矩形 1”，保留矢量形状与描边信息，是基础圆角轮廓。
- **模板·改**：同样的“矩形 1”，另有“图层 3”装饰，合成预览能看到上下金色花纹框。
- 这两份文件没有预置的智能对象换图层；不能把它们当成“双击智能对象、替换图片”的模板。

使用时放入新主体图，保持比例移动、缩放到画布内，使用矢量轮廓或对应蒙版裁切。带框版本保留装饰图层，使主体不遮住金色框。白色区域是待放图区域，不应作为最终白色背景盖住主体。

按 **301×461 画布**导出透明 PNG。装饰图层存在画布外内容（横向范围约为 -113 到 441），不要按“所有图层边界”扩画布或整体缩放，否则卡背比例和边框会变。圆角外不能填成白色或黑色。

此批仅检查原 PSD 的图层、矢量蒙版标记、尺寸和合成预览，没有替换已实装的104张卡槽背景。
