# 旅途委托

按作者2026年11月9日的 `AGENT_ADDITIONS_REVIEW.md` 与当日回复执行。每幕3项：固定三星强化精英，加两项加权随机村民委托。同时只接1项；放弃后该条永久关闭，仍可接其他任务。已完成的村民委托不再在之后的幕中生成。

任务和报酬分别抽取并保存，开关界面、接取和读档不重掷。小／中／大概率权重为1／2／3；未单独指定的奖励采用中等权重。三星Boss遗物权重1，其他三星分支权重2。强化精英每幕仍保留1项，使用三张不同的作者插图。

## 完成与跨幕

过幕自动放弃未完成委托；已完成未领奖的资格固定保存，可到旧幕任务板领取，不占新幕接取名额。上一幕有未领报酬时入口和上一幕按钮提示。除护送外，持有条件不消耗卡牌。

v3存档迁移只重建本幕未接取的旧委托；已接取、已领取和已放弃的合同及原报酬保持。v1／v2的早期六项板仍按原迁移流程归档。所有进度、计数去重键和报酬归属玩家独立存档，并沿用原生同步动作结算。

考试小瓶使用二代原生逃跑与战斗结束路径；逃跑不触发胜利任务及战利品。Boss战禁用且不消耗。多人共享当前战斗，治疗使用者，整队离开当前非Boss战斗。

四个委托魔具（含二星王室魔导书）不进营地店、普通战利品和普通工具生成池。魔术箱（MysticBox）弃用；原精灵时砂漏、不死鸟羽笔仅保留旧库存读取与一次性兼容，不再新增获取。普通魔具池现为7种。

## 强化精英与护送

接取三星委托后，下一场精英开战时强化初始敌人；多人同时接取不重复叠加。力量2／3／4，金属化4／6／8，再生3／5／7，或最大生命+25%，每场只用一种。放弃不撤销已经附加的强化。只有绑定该场战斗且仍存活的玩家获得任务进度。

贵重商品的运费逐卡保存：初始0，每个新地点+20，每次实际未格挡伤害−2，最低0。永久复制继承后分别计费，临时战斗副本不独立产生永久运费。下一位普通商人处自动移除货物并结算；放弃或未完成过幕只移除货物，不支付运费。主实现为 `CommissionState`、`CommissionCmd`、`CommissionCargo`、`CommissionScreen`。
