# 一代移植参考资料

这里保存了移植启动时完成的一代源码审计、需求、机制规范、开发规范、验收计划和逐项内容清单。它们来自一代仓库提交 `8604c9cd072dba6ae1bf8f47986fdc291b26c3cc`，用于核对遗漏内容和设计选择。

这些文档写于二代 0.5.2 交接包纳入本仓库**之前**。文中的“尚未开始二代运行时代码”“下一步 G0”等状态陈述已经过时；当前实现状态和测试结果以本仓库 `README.md`、`docs/HANDOFF.md`、`docs/TEST_REPORT.md` 和实际代码为准。文中的设计规范也不自动覆盖交接包已实现的行为；发现差异时需明确决定并更新相应测试。

- `01-一代基线审计.md`：一代源码事实、注册入口与统计口径。
- `02-需求文档.md`、`03-机制与交互规范.md`、`04-技术与开发规范.md`：移植目标与最初的设计提案。
- `05-实施与验收计划.md`、`06-决策与风险台账.md`：阶段计划和待确认问题。
- `inventory/`：一代逐项内容、资源、本地化差异及原始统计快照。

可选的审计重生成脚本为 `tools/audit_sts1_inventory.py`。默认读取本工作区上一级的 `reference/FrierenMod_STS1`；也可在当前进程设置 `FRIEREN_STS1_SOURCE` 指向完整一代源码 Git 仓库。运行脚本会覆盖 `docs/inventory/` 的生成文件，建议先确认来源提交并查看 Git 差异。正常构建与游玩不依赖该参考仓库。

原始一代素材、设计文件和参考 Git 仓库留在当前项目目录之外；它们没有复制到游戏模组仓库，也不属于本次清理可直接删除的资料。
