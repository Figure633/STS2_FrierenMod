# 阿乌拉（0.12.0源码核对）

- 全员芙莉莲队伍的新跑局，第二幕 Hive 固定阿乌拉；模组设置“允许遇到非芙莉莲模组Boss”开启后加入普通候选池。既有跑局保持已生成的Boss，其他角色旧档中的阿乌拉则修复为原生Boss。
- 阿乌拉200生命、200魔力；两名40生命士兵。魔力抵扣格挡后伤害，溢出扣血；士兵死亡削15魔力，并向玩家弃牌堆生成10张魔力。
- 仅开场获得0费、保留、消耗的解除魔法，仅能选择士兵。首次使用触发一次嘲讽。
- 普通行动优先级：裁决后行动、嘲讽、清场后的召唤、连击／冥想交替。每三次敌方行动所在回合结束时额外判定天平，不占用普通行动；玩家额外回合不推进计数。断头台不再按天平次数额外强化。
- 魔力总量沿用 `ManaCmd.Total`，计算抽牌堆／手牌／弃牌堆中的魔力牌数量。全芙莉莲联机队伍按存活玩家平均值比较，HUD同口径；联机同步仍待实机验收。
- 召唤要求至少40魔力但不扣魔力，召唤两名士兵，每三回合周期至多一次；意图公布后被打到不足40魔力时，召唤失败。士兵交替攻击／给阿乌拉格挡，数值见下表。
- 上方天平使用一代 `img/relics/ScaleOfObedience.png` 原图的秤盘及吊环，Godot绘制活动横梁与悬链，阻尼摆动。此素材只有128×128，高清美术可后续替换。阿乌拉立绘与解除魔法改用作者 TODO 内原作图片；士兵沿用附件。地图图标按作者最新参考重绘完整双角、刘海、蓬松侧发与辫子，无五官且统一单色；原稿为 Aura_node_source.png，128像素输出由 tools/render_aura_icon.gd 生成。
- 专项验证：构建 `Tests/Engine/EngineTests.csproj`，打包后运行 `tools/run-engine-check.ps1 -Mode aura-boss-only`；加 `-Snapshot` 输出 `artifacts/aura-layout.png` 布局预览。自动检查不代表完整跑局体验验收。

## 高低进阶与意图

进阶9（原生DeadlyEnemies）起使用高档，低于9使用低档。生命、初始魔力、行动顺序及冥想不分档。

| 单位／意图 | 实际效果 |
|---|---|
| 阿乌拉·魔法连击 BARRAGE | 低档6、高档7点伤害，3次；会受到力量等原生伤害修正。 |
| 阿乌拉·冥想 MEDITATE | 获得20魔力和2力量，与魔法连击交替。 |
| 阿乌拉·召唤 SUMMON | 至少40魔力即可召唤两名40生命士兵，不扣魔力；没有存活士兵且本3行动周期未召唤时优先使用。资源不足则失败。 |
| 阿乌拉·嘲讽 TAUNT | 空过并显示台词，只因首次使用解除魔法触发；天平回合或裁决优先时顺延。 |
| 阿乌拉·断头台 GUILLOTINE | 天平中阿乌拉魔力更高后，下次行动攻击1次。低档25、高档28基础伤害；再受力量等修正。 |
| 阿乌拉·失衡 STAGGER（眩晕意图） | 天平中玩家魔力更高后，下次行动不攻击，将自身生命及上限降至1，失去的生命转成魔力。 |
| 士兵·攻击 STRIKE | 低档8、高档10基础伤害1次。 |
| 士兵·防御 GUARD | 为阿乌拉获得低档10、高档12格挡。两名士兵分别从攻击／防御起步，此后交替。 |

每3次敌方行动结算天平，不单独占用普通行动；若本次为冥想，先按获得魔力前的数值判定，再获得20魔力，回合结束不重复判定。阿乌拉魔力更高时，存活玩家下回合能量重置后扣除低档1／高档2能量，随后移除服从；玩家更高时进入失衡；相等无效果。多人按存活玩家的平均魔力比较。士兵死亡使阿乌拉失去15魔力，每名存活玩家弃牌堆获得10张魔力。
