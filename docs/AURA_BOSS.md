# 阿乌拉首版（0.9.0）

- 全员芙莉莲队伍的新跑局，第二幕 Hive 固定阿乌拉；模组设置“允许遇到其他二层Boss”开启后加入普通候选池。既有跑局保持已生成的Boss，其他角色旧档中的阿乌拉则修复为原生Boss。
- 阿乌拉200生命、200魔力；两名40生命士兵。魔力抵扣格挡后伤害，溢出扣血；士兵死亡削15魔力，并向玩家弃牌堆生成10张魔力。
- 开场及每次天平后获得0费、保留、消耗的解除魔法，仅能选择士兵。首次使用触发一次嘲讽。
- 普通行动优先级：裁决后行动、嘲讽、清场后的召唤、连击／冥想交替。每三次敌方行动固定天平；玩家额外回合不推进计数。天平胜负与第三次后的强化按照当前设计结算。
- 魔力总量沿用 `ManaCmd.Total`，计算抽牌堆／手牌／弃牌堆中的魔力牌数量。全芙莉莲联机队伍按存活玩家平均值比较，HUD同口径；联机同步仍待实机验收。
- 召唤消耗25魔力，每三回合周期至多一次；意图公布后被打到不足25魔力时，召唤失败。士兵交替8伤害／给阿乌拉10甲。
- 上方天平使用一代 `img/relics/ScaleOfObedience.png` 原图的秤盘及吊环，Godot绘制活动横梁与悬链，阻尼摆动。此素材只有128×128，高清美术可后续替换。阿乌拉和士兵PNG直接复制用户2026-10-26提供的附件，场景裁去透明留白，未重绘。解除魔法首版复用 `Disperse.png`（分散）卡面。
- 专项验证：构建 `Tests/Engine/EngineTests.csproj`，打包后运行 `tools/run-engine-check.ps1 -Mode aura-boss-only`；加 `-Snapshot` 输出 `artifacts/aura-layout.png` 布局预览。自动检查不代表完整跑局体验验收。
