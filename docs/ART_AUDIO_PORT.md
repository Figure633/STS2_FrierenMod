## 音乐与语音

导入 16 个原音频：12 条跑局音乐、选人语音、原有杀人魔法语音文件（当前不触发）、胜利语音（当前不触发）和死亡结算配乐。MP3/OGG 保持原文件，不重新编码。

- 每章两首音乐由种子与章节序号选定，不调用卡牌、奖励或战斗随机数。二代不同分支章节共享对应章节序号的一代曲目。
- 普通战斗使用章节曲；精英、首领、商店与营地/事件各有映射；战斗结束回到章节曲。
- 两个节点进行 0.45 秒交叉淡化，结束后停用旧流。同一曲目的重复刷新不会从头播放。
- 音乐跟随 BGM 音量，Master 总线由游戏控制。玩家关闭“一代芙莉莲音乐”后立即恢复二代曲目；仅本地玩家为芙莉莲时生效。
- 死亡文件长约 83.7 秒，作为死亡结算配乐单次播放；不作为死亡瞬间的 SFX，避免忽略 BGM 音量并叠音。
- 选人语音通过 BaseLib 音效接口；建筑师阶段保留二代原生音乐与声音，不播放一代胜利语音。原先错误的攻击/施法通用语音绑定已移除。原 Java 代码仅在 OrdinaryOffensiveMagic 发动时播放 normal_attack.mp3；该牌尚未迁入，所以此台词不再从通用动作触发。窄范围补丁保留芙莉莲 Attack/Cast/PowerUp 的动画和等待时间，卡牌/命中特效音保持原生路径。其他角色与受击/死亡不受影响。
- 第四章、旧主菜单、菲伦、镜像 Boss 等尚无相应玩法入口，未迁入这些音频。

## 保留项

多人手势、出牌轨迹、转场、卡牌边框及少数能力占位图暂保留现有实现。`rest_sleep`、能量球暗态等相关原始图已收录，当前场景使用二代原生变暗/静态营地行为。没有修改咏唱规则或玩家存档结构。

原始素材保留来源与作者署名，本包只部署本机测试；未发布 Workshop。
