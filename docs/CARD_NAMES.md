# 卡名查阅

根目录 `卡名对照表.xlsx` 只保留 ID、二代中文名、二代英文名、卡面效果（中文）四列。效果有升级差异时在同一格分列普通与升级；选择预览和自定义牌注明内容随实际选择变化，不用测试中的零值冒充固定效果。

中文以作者核对结果为准。英文保留作者选定的专有名称，并润色不自然的表达。`docs/inventory/card_names.jsonl` 提供相同数据，供按 ID 快速检索。

`BloodSpell` 表内“不消耗魔力，失去 X 点生命”新规则已由作者决定暂不实装，保留待办，游戏暂保留原规则。`SayThinkingSpell` 已确认从抽牌堆顶自动出牌。

`tools/export_card_names.mjs` 从索引导出四列表，运行前会核对游戏名称；表中若有未回写索引的人工修改则停止覆盖。不能再从一代重新生成并覆盖作者的选择。人工核定新内容时先同步本地化和索引，再显式使用 `--from-reviewed` 导出。
