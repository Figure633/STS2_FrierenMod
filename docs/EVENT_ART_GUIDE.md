# 事件图片尺寸

0.10.10，依据原生1920×1080设计视口及当前FrierenEventLayout锚点核对。

- 整张事件背景：1920×1080（16:9）；高清可用3840×2160。
- 仅左半边插画：960×1080（8:9）；高清可用1920×2160。
- 左图按宽高比等比铺满左侧50%区域，多出的部分会裁掉。主体、脸与重要文字请留出边缘安全区；不同宽高比窗口会产生额外裁切。
- 当前接口仍只读取每页的一张图，左侧用原图，整屏背景复用该图并压暗；右半边叠文字暗底。无需将右侧文字画进图片。若想让左右背景分别使用不同图片，需要另加独立背景资源入口。

九个事件共用该布局：新的开始、踏上美食之旅、克拉伏特的礼物、冒险物语：动物井、遭遇宝箱怪、封魔石矿山、魔王军来袭、冒险物语：空洞骑士、冒险物语：JOJO的奇妙冒险。新图按各自页面资源替换；魔王军来袭使用作者Word原图，可用 `tools/extract_event_art.py` 按事件标题提取。

0.12.19：JOJO使用已有的1280×1875竖版海报（Previewjojo.png），左侧完整等比显示，不裁掉人物或海报文字，保留ononotsu署名。横图和其他明确要求完整构图的插画也按各自事件的KeepAspectCentered配置展示。
