## 其他新增模型与移植适配

下列区别需要保留，不能把“C#新建文件”一概说成“代理原创”：

- 长蛇戒指 KraftSerpentRing：代理为二代缺少一代原生戒指作的兼容模型，每回合多抽一张；作者最新Word明确保留这一事件奖励及效果。不是一代模组自定义遗物的直接同名移植，也不是当前完全未确认的奖励。
- 解除魔法、贵重的商品、三个好运愿望选项、黑金之翼、封魔矿及矿山、魔王军来袭：属于作者要求的玩法或其衍生模型。其中魔王军三档奖励已由作者明确回复，不列作代理擅定奖励。
- 生生流转、葬送的芙莉莲、星星之火及赖床／起床等新增卡：当前需求记录中有作者的先古卡和新增卡设计；不能因一代没有同名Java文件就认作代理原创。
- SustainedBarrage、ReadyStance、ViolentExorcism、MetalPetalSpell等和一代类名不同，卡名索引记录了移植对应关系；咏唱槽选择、魔法自定义选项的展示模型也属于界面实现。
- 本次新增 BindingStrengthDownPower 是复用原版临时减力量结算、去除“尖啸”来源卡预览所需的能力身份，不增加拘束魔法效果。
- 旧“准备架势优先抽牌堆”的解释、成就和标题的gold标签、复制体准备回合合并攻击、阿乌拉召唤遗留魔力门槛，属于代理写入的说明或行为问题；本次按作者反馈修正。

本清单能证明的范围以本地记录为限。缺少逐项确认的项目明确列作待复核，没有宣称已还原当前工作区之外的全部聊天批准历史。

拘束魔法出现尖啸卡图，是复用了原版 PiercingWailPower，该能力会自动显示其来源卡的预览，并非拘束魔法插画文件被替换。当前调用和来源核查只发现这一处错误来源预览；封魔矿只借用了 DarkShacklesPower 图标，没有施加该原版能力。其他原版负面状态牌的预览若对应实际生成效果则应保留。

## 遗物图片较小的排查
