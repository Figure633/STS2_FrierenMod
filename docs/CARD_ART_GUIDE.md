# 自己微调卡图

卡图只需要人物和背景。卡名、费用、边框、类型牌、正文都由游戏自动叠上去，不要画进图片里。

| 卡牌 | 导出尺寸 | 构图重点 |
|---|---|---|
| 普通攻击、技能、能力 | 500×380 PNG | 等比裁剪，铺满画布；脸不要挤在四角，顶部横幅和能力卡底部弧形框也会遮住一些内容。250×190也是同一比例，但500×380更清晰。 |
| 先古卡 | 598×842 PNG | 这是整张竖幅插画。标题遮住顶部，下半幅被类型牌和说明框遮住，脸与场景中心尽量放到上半幅。 |

## 在修图软件里操作

1. 新建对应尺寸的画布，把原图作为单独一层放进去。保留一份原图，不在原文件上反复裁剪保存。
2. 缩放图片时锁定宽高比例，移动图片选择构图。不要把横图直接拉长成竖图；可以让四周背景超出画布，由导出时裁掉。
3. 做先古卡时，把 [遮挡参考层](../assets/card_sources/先古卡遮挡参考层.png) 放到最上面，位置为0、0，尺寸保持598×842。红色区域可能被游戏界面挡住，绿框是放脸的保守参考范围。眼睛、嘴和下巴都应留在说明框上面。参考层不能替代真实卡面预览。
4. 隐藏参考层，导出PNG。确认没有黑边、空白边、人物变形，也没有把参考线一起导出。保存编辑工程，之后只需移动或缩放图片层就能微调。

- [葬送的芙莉莲原图](../assets/card_sources/FrierenTheSlayer.png)：当前版本把图片等比缩到598像素宽，再向上移80像素；脸约在y=125～365，眼睛约在y=210，避开下半部说明框。这些数值只适用于这张原图。

成品分别是 [生生流转](../FrierenMod/images/cards/EndlessFlow.png) 和 [葬送的芙莉莲](../FrierenMod/images/cards/FrierenTheSlayer.png)，可用来对照。
