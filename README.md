# FrierenMod_STS2

芙莉莲一代模组的二代移植测试版，版本 **0.6.4**。魔法书接入原版卡组查看所用的上层界面容器，打开时接管奖励、地图上方的活动屏幕与输入，关闭时由原版恢复；奖励领完等待前进期间同样允许使用魔具。

0.6.3：初始因子选择在加载和转场结束后恢复，退出时取消旧等待，保留已选槽位和当前选项；选择期间使用原生接口关闭地图，完成后恢复。三槽选完赠送两个神奇妙妙工具，旧档补赠一次，消耗或跨幕后不重复发放。首次教程仍为待办。

0.6.2：新增魔法使流终结技、变出热茶的魔法、定叫他有来无回和普通攻击魔法的战斗实际数值预览，复用原生计算变量与增减益高亮。

0.6.1：魔具成功使用时闪一次绿光，消耗的魔具和因子淡出，新增因子与魔具使用原版卡牌飞入特效及粒子拖尾，终点为魔法牌组图标；奖励、魔具店和控制台等获取入口共用这一动画。修正右键输入优先级、缩放后的点击区域，以及动画卡牌复用时的输入状态残留。拾取战利品期间也可打开魔法牌组右键使用魔具，关闭后恢复原奖励列表。

0.6.0 补入17件有效一代遗物、3种药水及遗物依赖的4张衍生牌；4件原Boss遗物按作者决定暂入稀有池，2件事件专属遗物先加入本体，宝箱怪事件后续移植。菲伦发饰保留Starter限制；海塔法杖按作者决定废弃，仅保留旧档ID，不再获取或生效。不加入空壳的StarkRelic。

本版修正魔法牌组的鼠标交互；控制台与加牌命令新增的因子、魔具统一进入魔法牌组。同时修正魔力类型名称、状态与诅咒的原生卡框，以及进化的防御魔法的敏捷预览。

0.5.12 已由作者核对：魔力的四种同调卡图与说明、衍生牌百科分类、规则悬停和衍生牌预览、咏唱三槽与禁用显示、槽位标题残留清理，以及生成卡牌的原生飞入动画。仍需正式游戏长局试玩，不是整个一代模组的完整移植。

给作者接手：先阅读 [先读我-作者接手.md](先读我-作者接手.md)，再看 [代码导览与待办](docs/HANDOFF.md)。源码包包含当前完整工作树，不要求本地 Git 历史；首次教程仍是待办。

- 专注、削弱、限次免耗和想象力；普通咏唱按指定强度，精准/终极按各牌堆原始费用系数计算强度。

- 圣徽仍在每回合抽牌后向抽牌堆与弃牌堆各加入 1 张魔力。基础同调抽牌，节俭允许魔力弃置复用，雷电魔法可替换同调效果。

## 试玩方法

启用 **BaseLib + FrierenMod**，推荐新建芙莉莲测试局。先完成三次因子选择，检查魔法书中三个槽都有因子。第一场战斗观察抽牌堆和弃牌堆生成的魔力，然后打出快速咏唱，选择一个能支付费用的槽位。

打出魔力属于“同调”，会消耗那张魔力；用于咏唱前请保留对应牌堆的资源。精准/终极咏唱在没有可用槽位时不可手动空打。想象力期间普通牌显示 0 能量，但仍按原费用扣魔力；X 费牌保留二代原生能量行为。

到营地选择「逛魔具店」，选两件并确认。打开右上角「魔法因子」，右键一张魔具，再左键选择其所需因子或材料；选满自动生效。可再次右键或按 Esc 取消。推荐先选盲盒和神奇妙妙工具：用盲盒获得库存因子，再用工具替换一个已装载因子。魔具和槽位随二代原生楼层检查点保存，中途退出按原生规则回退本房间；不会单独保存收益却重置营地行动。旧 v1/v2 因子数据自动读取，新增魔具使用 v3 格式。详细测试结果及待试玩项见 `docs/TEST_REPORT.md`。

## 构建与测试

基线：Windows、StS2 **v0.107.1**、BaseLib **v3.4.7**、.NET SDK **9.0.306**、Godot **4.5.1**。生产模组使用普通 .NET SDK；真实引擎测试工程另用 Godot .NET SDK。

非默认游戏安装目录可复制 `local.props.example` 为 `local.props` 调整路径。基础构建：

```powershell
./tools/build.ps1
```

资源打包与完整引擎测试：

```powershell
./tools/build.ps1 -Pack -EngineTests `
  -GodotPath "D:/Tools/Godot/Godot_v4.5.1-stable_win64_console.exe" `
  -GodotMonoPath "D:/Tools/GodotMono/Godot_v4.5.1-stable_mono_win64_console.exe"
```

测试工程 `Tests/Engine` 使用实际 sts2/BaseLib 程序集和补丁，以及游戏的内存测试存档。它不访问玩家进度；Godot 的独立配置使用 `FrierenChantTests` 目录。构建脚本从 `local.props` 读取游戏与 BaseLib 路径，并从 `-GodotMonoPath` 查找随附 NuGet 包；无需修改测试源码。

发布暂存目录为 `artifacts/FrierenMod/`。脚本不会自动部署。变更图片/文本必须重新打包 PCK，不能只替换 DLL。重建来源素材运行 `python tools/import_assets.py`，会同时生成原生动画场景和来源清单。源码包包含已转换的全部模组资源，常规构建不需要一代仓库。重新生成素材时，用当前进程的 `FRIEREN_STS1_SOURCE` 指向一代源码，详见交接说明。

## 范围和适配差异

- 旧骨骼仅有 Idle 动作。以 24 fps 烘焙为 Godot 网格，保持一代 1.2 倍播放速度；其余动作是二代适配反馈。营地使用透明底完整阅读坐姿，商店复用待机。细节见 `docs/ART_AUDIO_PORT.md`。
- 一代三张结局图和胜利语音暂不用于二代建筑师阶段；二代分支章节按章节序号对应一代音乐，没有移植一代第四章/碎心流程。部分未移植卡牌的专用语音、菲伦素材不进入当前包。
- 多人手势、过场擦除、出牌轨迹、卡牌边框及部分能力图标仍用原生/临时素材。菲伦、事件/Boss、其余遗物和药水尚未实现。
- 专属营地和八种可获得魔具已迁入；一代 Tutorial 不进入营地池，背景皮肤解锁/成就未移植。已移植的自定义遗物只有圣徽，未对所有二代遗物和事件组合完成兼容验收。
- 魔具使用与专属营地选项当前仅支持单人，多人显示禁用说明；尚未完成网络动作同步。随机效果使用玩家奖励 RNG，保留效果范围但不保证与 Java 版同种子逐次结果相同。
- 因子奖励是独立因子池，未混入一代的可使用魔法道具；谜题因子在奖励池开放，尚无一代的配置开关和教学/历史页面。
- 免耗后的实际费用用于普通咏唱可用性判断；无可用槽位时阻止精准/终极空打。终极咏唱每个因子回调一次，未复制一代首槽重复回调的行为。
- 催眠按一代实现使用实际魔力费用决定层数；生血魔法保留负费用偏移。想象力按修改后的实际普通费用代付，X 费牌使用能量。
- 本次仅供本地测试，不发布 Workshop。一代素材来源及 SHA-256 记录在 `docs/assets.json`；两张新素材由内置 image_gen 生成，路径、提示词与哈希见 `docs/generated_assets.json`。接口未暴露模型版本，不能确认是 IMAGE 2.5。原图仍保留。

代码按角色模块组织，普通卡牌每张独立文件并按稀有度分类；详见 [代码结构与菲伦接入约定](docs/CODE_STRUCTURE.md)。规则集中在 `Core/Frieren/`，游戏命令集中在 `Scripts/Frieren/Mechanics/`，因子统一使用目录和效果分发，卡牌复用原生命令；没有引入一代的 ActionQueue 或全局当前卡牌。
