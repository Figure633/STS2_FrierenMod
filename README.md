# FrierenMod STS2

《杀戮尖塔2》的芙莉莲模组，移植自[一代模组](https://steamcommunity.com/sharedfiles/filedetails/?id=3164722329)。当前为游戏 **beta v0.113.0** 的适配分支，模组版本 **0.13.2**。正式版请使用 main 分支。

芙莉莲使用抽牌堆、手牌与弃牌堆中的魔力进行咏唱，可装配因子、使用魔具，包含专属卡牌、遗物、事件、委托与Boss。多人游戏双方需使用相同版本的模组和BaseLib；混合角色队伍保留原版事件和Boss池。

## 安装

依赖 **BaseLib 3.4.8**；使用3.4.8时保留其随附的兼容助手。完整更新 `FrierenMod.dll`、`FrierenMod.pck` 和 `FrierenMod.json`，放入游戏的 `mods/FrierenMod/`，重启游戏并启用模组。

## 构建

使用 .NET SDK 9.0.306、Godot 4.5.1和游戏程序集。将 `local.props.example` 复制为 `local.props`，配置本机游戏、BaseLib及Godot路径。

```powershell
./tools/build.ps1
./tools/build.ps1 -Pack -GodotPath "D:/Tools/Godot/Godot_v4.5.1-stable_win64_console.exe"
./tools/install.ps1
```

构建结果位于 `artifacts/FrierenMod/`；安装前需退出游戏。基础构建包含规则、集成、接口及资源检查。引擎检查另加 `-EngineTests -GodotMonoPath <Godot .NET路径>`，会使用内存测试存档。自动检查不能代替实际游戏验收。

源码位于 `Core/` 和 `Scripts/`，运行资源位于 `FrierenMod/`，测试位于 `Tests/`，构建与资源处理工具位于 `tools/`。常规构建不需要作者的需求文档或素材原稿。

## 本地双版本

同一仓库使用两个独立工作目录，正式版目录 FrierenMod_STS2 对应 main，测试版目录 FrierenMod_STS2_beta 对应 beta。各自的 artifacts/FrierenMod 保留对应的 DLL、PCK 和清单。

Steam 切换游戏分支并退出游戏后，在对应工作目录执行：

```powershell
./tools/install.ps1
```

安装脚本会核对构建时的游戏和 BaseLib 指纹。游戏或依赖再次更新时，需要在对应目录重新构建。两个模组包共用游戏里的 mods/FrierenMod 安装位置，每次切换游戏分支后安装对应包。
