# FrierenMod STS2

《杀戮尖塔2》的芙莉莲模组，移植自[一代模组](https://steamcommunity.com/sharedfiles/filedetails/?id=3164722329)。当前版本 **0.13.20**，开发中。

0.13.20 新增俄语本地化，沿用二代原版术语及俄语数词词形，覆盖卡牌、事件、委托和魔法书等游戏内文本。

0.13.19 新增韩语本地化，覆盖卡牌、遗物、事件、委托和魔法书等游戏内文本。

0.13.18 新增日语本地化，覆盖卡牌、遗物、事件、委托和魔法书等游戏内文本。

0.13.17 修复 Android 上 SL 后魔法牌组未恢复、需要重选因子的问题，并绕开手机版历史存档补丁的初始化异常。

0.13.16 新增默认关闭的“卡牌与遗物音效”选项：赖床使用一代睡眠音效，飞吻、普通攻击魔法及镜莲花戒指沿用一代音效；婴儿般的睡眠不播放音效。
0.13.15 新增成就卡背“出现吧，神龙！”，完成一次神龙许愿后解锁，使用作者提供的原图。
0.13.14 修复海克斯魔盒独立变牌池混入因子和衍生牌；隐藏精灵的沙漏与不死鸟的羽笔的百科条目；兼容 Regent Anime 原卡图缓存失效后的刷新。
